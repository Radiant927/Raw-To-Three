# 拍摄指南：怎么拍才能让 COLMAP pipeline 出好结果

标准 pipeline：COLMAP SfM → 2DGS 训练 → Gaussians。COLMAP 是个"拼图"算法——
它要从照片里找共同特征点，才能把照片拼到同一个 3D 坐标系里。拍得对，
40-80 张就能出金标准质量（参考图书馆 163K Gaussians）；拍得不对，再多张也是孤岛。

## 核心原则

**每一张照片都要"认得"前一张照片里的东西**，连续移动地拍，不要分组拍。

## 正确做法

### 1. 拍摄路线：绕建筑走一圈

```
        ┌──────────┐
        │  建筑    │
   ↗────│          │────↖
  /     │          │     \
 /  ④───│          │───①  \
│  |    │          │    |  │
│  ③←─←─│          │─→─②  │  ← 绕着走
│  |    │          │    |  │
 \  ⑤───│          │───⑦  /
  \     │          │     /
   ↘────│          │────↙
        └──────────┘
           ⑥ ← 从不同高度多走几圈
```

- 站在离建筑 5-15 米远，绕着它**连续走**
- 每走 1-2 步拍一张，不要走太远才拍
- 也可以同一个位置不同仰角多拍几张

### 2. 相邻重叠：60-80%

新拍的一张里，要能看到上一张里 60% 以上的场景。简单说：
- 原地转身的话，**每转 15-20° 拍一张**（一圈拍 18-24 张）
- 边走边拍的话，每步 (~1米) 一张

### 3. 关键：在转角/屋檐拍"桥接照片"

这是 oneshop 失败的**唯一原因**。走的时候：
- 到了墙角，**慢下来**，拍几张同时能看到两面墙的
- 到了屋檐下方，拍几张同时能看到屋顶和墙面的
- 这些"桥接照片"把不同区域串起来，COLMAP 才不会分裂成孤岛

### 4. 相机设置

| 项目 | 建议 |
|---|---|
| 焦距 | 全程不要变（别拉变焦），用手机默认 1x |
| 对焦 | 锁焦（长按屏幕锁 AE/AF） |
| 曝光 | 避免过曝/欠曝太严重，亮暗差大的场景拍 HDR |
| 横竖 | 一致就行，不要一半横一半竖（横拍更推荐，视野宽） |
| 分辨率 | 最高像素 |
| 运动 | 按快门时站稳，别边走边拍会糊 |

### 5. 数量参考

| 场景大小 | 建议张数 |
|---|---|
| 小建筑 / 店铺外观 | 40-60 张 |
| 中型建筑（图书馆那种） | 60-100 张 |
| 大建筑/多立面 | 100-150 张 |

**张数不是越多越好**，关键是连续性和重叠。oneshop 有 72 张但全是孤岛，
不如绕一圈拍的 40 张。

## 绝对不要做的事（oneshop 踩的坑）

❌ **分组独立拍**："拍一组正面、一组背面、一组屋顶、一组侧面"——
   COLMAP 看到的是几堆完全没有共同点的照片，拼成 3 个独立模型

❌ **视角跳变**：站在一个点猛拍 10 张，然后走到完全不同的位置再猛拍 10 张

❌ **大片空白/天空/树为主**：SIFT 特征在树叶和天空上不稳定，桥接照片里
   要尽量包含建筑结构（墙面、屋檐、窗框等有特征的部分）

❌ **全是远景或全是近景**：混一些中景帮助定位

## 拍好后检查（10 秒）

把照片按顺序翻一遍，像看视频一样：
- 能看到场景**连续移动**而不是跳来跳去 → ✅
- 有几张照片能看到两个相邻区域（比如同时看到墙+屋顶）→ ✅ 桥接有了
- 某两张之间完全找不到共同点 → 补几张过渡的

## 出问题时 Pipeline 会提前警告

我们的 `run_colmap.py` 已经加了早期检查：
- 如果 COLMAP 注册率 < 50% 或相机 < 20 → 立即中止（不浪费 GPU 时间）
- 如果 COLMAP 生成多个独立模型 → 立即中止

所以即使拍得不好，3 分钟就能知道问题，不会再等 48 分钟训练完才发现。
